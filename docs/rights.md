# Licensing And Standards Rights

This page is for anyone who wants to reuse this repository or the standard's text: it says what the project's licence covers and what it does not.

The Apache-2.0 licence covers the original material in this repository: the schema's structure, the source code and the project's documentation.

ISO holds the copyright in its publications, the text of ISO/IEC 27001 and ISO/IEC 27002 among them.

The project's licence grants no right to reproduce, redistribute or sublicense ISO's text. When you use this schema in a tool or a data pipeline, write your own control statements or refer to the licensed text, and embed the standard's text only with ISO's permission. [OVERLAY.md](https://github.com/lmodel/iso27001/blob/main/src/iso27001/schema/OVERLAY.md) says how a licence holder keeps that text in a private copy of the schema.

The repository keeps ISO's own metadata records of ISO/IEC 27001:2022 and the standards around it, from ISO Open Data, under the ODC Attribution License (ODC-By) v1.0, and [NOTICE](https://github.com/lmodel/iso27001/blob/main/NOTICE) gives the attribution. It leaves out each record's scope, which summarizes the standard in ISO's words.

For a licence to use ISO's text in software or in a governance, risk and compliance (GRC) product, contact ISO at <customerservice@iso.org>.
